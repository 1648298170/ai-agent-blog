# 使用指南

## 这套东西怎么用

本博客是《企业级 AI Agent 全栈工程师 · 23 周每日执行手册》的配套教程：

- **手册** = 执行清单：每天学什么、做什么、产出什么
- **博客** = 教材：把手册里的一句话任务展开成完整教程（概念 → 代码 → 踩坑 → 自测）

## 每天的节奏（2–3 小时）

```text
1. 读教程（约 40–60 分钟）
   打开本日教程，先通读"概念讲解"，理解为什么再动手

2. 敲代码（约 60–90 分钟）
   跟着"动手任务"一步步做，代码要自己敲，不要复制粘贴

3. 自测（约 15 分钟）
   回答文末"自测问题"，答不上来的回去重读对应小节

4. 记录（约 15 分钟）
   提交代码到 Git，写 3 行日报：学了什么 / 产出了什么 / 卡在哪里
```

## 每周的节奏

- Day 1–6：学习 + 动手
- Day 7：周复盘（参考第 1 周 Day 7 的复盘方法论）

## 卡住了怎么办

1. 先看教程"常见踩坑"小节——80% 的问题都在里面
2. 报错信息直接搜索，优先看官方文档和 GitHub Issues
3. 问 AI 时把**完整报错 + 你做了什么**贴上，不要只贴一句话

## 教程进度

**23 周全部 161 篇教程已完结**。侧边栏按 5 个阶段组织，每周包含周概览（日程表 + 参考资源）和 Day 1–7 七篇教程，也可以用左上角搜索快速定位主题。

::: tip 学习节奏建议
不必严格按周历执行——但顺序强烈建议保持：每周的教程都建立在前一周的产出之上（第 4 周的数据库就是第 10 周 SQLAlchemy 的库、第 17 周记忆直接复用第 14 周的 pgvector）。
:::
