# 学习指南：以落地三个产品为目标

## 你的毕业目标

23 周走完，你手里不该是一堆零散知识点，而是**三个可落地的产品方向**（每个都有你自己跑通的项目兜底）：

| 产品线 | 一句话定义 | 对应课程 |
| ---- | ---- | ---- |
| **知识库问答** | 企业文档进得去，带引用的准确答案出得来 | 第 14–15 周（RAG 全链路）+ 第 18 周（MCP 接入） |
| **文档智能** | PDF / Word 上传 → 解析 → 结构化入库 → 问答的完整管线 | 第 14 周 Day 2–3 + 第 15 周 Day 6 |
| **客服系统** | 多轮对话 + 业务操作（查订单 / 退款）+ 高危操作人工审批 | 第 12–13 周 + 第 5 周（认证）+ 第 20 周（平台化） |

最重要的认知：**三条线共用同一套引擎**——Agent 循环（第 11–13 周）、检索（第 14–15 周）、记忆（第 17 周）、评估（第 16 周）、生产化（第 21 周）。学引擎，就是在为三条线同时铺路；所以前 13 周不要问"这和我做知识库有什么关系"，关系在第 14 周之后全部兑现。

## 标杆产品：怎么研究、何时研究

三步法（对每个标杆都用）：

1. **用**：注册或部署，拿一个真实任务走全流程（上传一份真 PDF 再提问；在 Fin 演示里问一个它答不了的问题，看怎么转人工）
2. **拆**：每个功能问四个问题——解决什么痛点？背后大概是什么技术（对照你学的哪一周）？它没做什么（漏掉的常是机会）？换成你会怎么做？
3. **写**：每个标杆留半页分析笔记进你的笔记库——第 22 周写简历、备面试时，这些笔记就是弹药

研究节奏（别在第 1 周就去拆产品，先建后拆校准才有意义）：

- **第 14 周起**：每周花 1–2 小时同步拆当周对应的标杆（学 RAG 时拆 FastGPT 的切块配置，学客服时玩 Fin 的转人工）
- **第 19 周**：课程带你上手 Dify，那时你的 v4 已能和它逐功能对比——产品 sense 就来自这场对比
- **第 22 周**：研究笔记直接变成简历与面试素材

## 每天的节奏（2–3 小时）

```text
1. 读教程（约 40–60 分钟）
   打开本日教程，先通读"概念讲解"，理解为什么再动手

2. 敲代码（约 60–90 分钟）
   跟着"动手任务"一步步做，代码要自己敲，不要复制粘贴

3. 自测（约 15 分钟）
   回答文末"自测问题"，答不上来的回去重读对应小节

4. 记录（约 15 分钟）
   提交代码到 Git，写 3 行日报：学了什么 / 产出了什么 / 卡在哪里
```

## 每周的节奏

- Day 1–6：学习 + 动手
- Day 7：周复盘（参考第 1 周 Day 7 的复盘方法论）

## 卡住了怎么办

1. 先看教程"常见踩坑"小节——80% 的问题都在里面
2. 报错信息直接搜索，优先看官方文档和 GitHub Issues
3. 问 AI 时把**完整报错 + 你做了什么**贴上，不要只贴一句话
