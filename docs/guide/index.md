# 学习指南：双引擎路径（Node + TS 主线 · Python 进阶）

## 你的毕业目标

23 周走完，你手里不是一堆零散知识点，而是**三个可落地的产品方向**（每个都有你自己跑通的项目兜底）：

| 产品线 | 一句话定义 | Node + TS 主线即可实现 |
| ---- | ---- | ---- |
| **知识库问答** | 企业文档进得去，带引用的准确答案出得来 | OpenAI 兼容 Embedding + pgvector + 引用溯源（TS 全链路） |
| **文档智能** | PDF / Word 上传 → 解析 → 结构化入库 → 问答 | pdf-parse 提取 + AI SDK 结构化输出（扫描件走云 OCR API） |
| **客服系统** | 多轮对话 + 业务操作 + 高危操作人工审批 | AI SDK 工具循环 + needsApproval 审批 + 渠道接入 |

最重要的认知：**三条线共用同一套引擎**——Agent 循环（第 11 周 AI SDK）、检索（RAG 补篇）、记忆、评估（第 16 周）、生产化（第 21 周）。学引擎，就是在为三条线同时铺路；所以前 13 周不要问"这和我做知识库有什么关系"，关系在第 14 周之后全部兑现。

## 两条学习路径

### 主线：Node + TS（推荐首选）

适合：前端 / JS 工程师，或想**用最熟悉的技术最快落地**的人。全程只用 TypeScript——Agent 循环、RAG、MCP、评估都有成熟的 TS 实现（AI SDK 6 月下载 2000 万+，MCP 官方 TS SDK，promptfoo 原生 JS）。

**主线学习序列**（周编号对应侧边栏目录，顺序即学习顺序）：

```text
第 1-8 周   全栈底座：TS/Monorepo → Next.js → NestJS → PG/Prisma
            → 认证 → Redis → Docker/CI → 云部署
第 11 周    LLM API 原生 + AI SDK：裸 API → 流式 → FC → 结构化输出
            → streamText/useChat → needsApproval 审批
第 16 周    评估工程：promptfoo（JS 原生）+ judge + CI 门禁（Day 4/6 为 TS 主日）
第 20 周    全栈整合：Next.js + NestJS BFF + Agent 服务
第 22-23 周 简历 + 面试冲刺
```

**主线补篇**（让 TS 主线完整覆盖三大产品的关键增量，陆续发布）：

- Agent 循环 TS 深入：ToolLoopAgent 多步任务 + 手写循环对照 + 多 Agent 模式
- RAG TS 全链路：切块 → Embedding → pgvector → 混合检索 → 溯源
- MCP TypeScript SDK：Server / Client / 审批
- 记忆 TS 版：会话记忆 + 用户偏好 + 语义缓存

### 第二引擎：Python（进阶选修）

什么时候再学 Python：

1. 目标岗位是 **AI 平台 / 算法应用团队**（JD 硬性要求 Python）
2. 需要 run 本地模型或 Python 独占生态：Ragas / DeepEval / PaddleOCR / sentence-transformers
3. 要和公司的算法团队（Python 存量）协作

内容就是侧边栏里的第 9-10 周（Python/FastAPI）与第 12-19 周的 Python 实现（LangGraph/DeepEval/记忆/安全实验）——**它们没有被删除，只是从主线后置为第二引擎**。有第 1-8 周的 JS 功底，第 9 周的对照式教学能让你 2-3 周上手 Python。

### 两条路径的取舍口诀

- 前端出身、想最快落地三大产品、目标 AI 应用岗 → **TS 主线**
- 目标 AI 平台 / 算法应用团队、需要本地模型与数据处理深度 → 主线之后补 Python
- opencode 本身就是纯 TS 手写循环的顶级 Agent——TS 主线的天花板足够高

## 标杆产品：怎么研究、何时研究

三步法（对每个标杆都用）：

1. **用**：注册或部署，拿一个真实任务走全流程（上传一份真 PDF 再提问；在 Fin 演示里问一个它答不了的问题，看怎么转人工）
2. **拆**：每个功能问四个问题——解决什么痛点？背后大概是什么技术（对照你学的哪一周）？它没做什么（漏掉的常是机会）？换成你会怎么做？
3. **写**：每个标杆留半页分析笔记进你的笔记库——第 22 周写简历、备面试时，这些笔记就是弹药

研究节奏（别在第 1 周就去拆产品，先建后拆校准才有意义）：

- **主线进入 Agent 篇起**：每周花 1-2 小时同步拆当周对应的标杆
- **第 19 周**：课程带你上手 Dify，那时你的 v4 已能和它逐功能对比——产品 sense 就来自这场对比
- **第 22 周**：研究笔记直接变成简历与面试素材

## 每天的节奏（2-3 小时）

```text
1. 读教程（约 40-60 分钟）
   打开本日教程，先通读"概念讲解"，理解为什么再动手

2. 敲代码（约 60-90 分钟）
   跟着"动手任务"一步步做，代码要自己敲，不要复制粘贴

3. 自测（约 15 分钟）
   回答文末"自测问题"，答不上来的回去重读对应小节

4. 记录（约 15 分钟）
   提交代码到 Git，写 3 行日报：学了什么 / 产出了什么 / 卡在哪里
```

## 卡住了怎么办

1. 先看教程"常见踩坑"小节——80% 的问题都在里面
2. 报错信息直接搜索，优先看官方文档和 GitHub Issues
3. 问 AI 时把**完整报错 + 你做了什么**贴上，不要只贴一句话
