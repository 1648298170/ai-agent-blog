# 第 22 周：系统设计 + 项目复盘 + 简历

> 所属阶段：全栈整合 + 生产化 + 面试冲刺（第 20–23 周）

## 本周目标

完成系统设计专项训练（缓存 / 队列 / 异步任务）与项目复盘，用 STAR 法则重写三个里程碑项目，产出成果导向的简历初稿与终稿。

## 本周日程

| 天 | 学习内容 | 动手任务 | 当日产出 |
| --- | --- | --- | --- |
| Day 1 | 系统设计基础：需求收集 → 高层设计 → 深入组件 | 用 45 分钟设计“AI 客服 Agent 平台”，画出架构图 | 架构图 + 设计文档 |
| Day 2 | 缓存三件套：穿透/击穿/雪崩 | 针对你的平台，写出每个问题的具体防护方案 | 缓存设计文档 |
| Day 3 | 消息队列 + 异步任务设计 | 设计“文档上传 → 异步向量化 → 通知”的队列方案 | 队列设计 |
| Day 4 | 项目复盘：用 STAR 法则重写三个里程碑 | 每个项目写：Situation/Task/Action/Result，重点写架构决策和踩坑 | STAR 文档 |
| Day 5 | 简历优化：把项目写成“成果导向” | 用“量化结果 + 技术关键词”重写项目描述 | 简历初稿 |
| Day 6 | 模拟面试：项目深挖 | 找朋友或用 AI 模拟面试官，追问“为什么用 LangGraph”“死循环怎么防” | 模拟面试记录 |
| Day 7 | 周复盘 + 整理 | 根据模拟反馈修正简历和项目描述，写周记 | 简历终稿 + 周记 |
