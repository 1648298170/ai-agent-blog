## 今日目标

1. 把 Day 5 的模拟反馈和 10 份目标 JD 拆成关键词，对照出短板清单，知识性的今晚补完

## 为什么是今天投，而不是「再准备准备」

到现在这个节点，最容易犯的错不是投错岗位，是不投。

理由有三个。第一，准备的边际收益已经见底。八股 40 题、系统设计白板、图论算法、45 分钟完整模拟面试，全都过了。这时候再看一天笔记，能涨的分可能是一两道题；投出去，换回来的是真实市场的反馈，哪个话术有人回、哪个项目讲述被打断、哪道追问答不严，这些信息闭门造车永远拿不到。

第二，流程有周期。投递到约面通常 3 到 7 天，一面到终面走完 1 到 4 周都算正常。你今天投，日历上最早的面试也排在下周。等待期正好拿来继续补短板，学习窗口和流程窗口是并行的，不冲突。

第三，求职是漏斗不是考试。投递、约面、一面、二面、Offer，每一层都有转化率，转化率只有漏斗流动起来才测得出。攥着简历不投，等于拿着考卷不进考场，还安慰自己在复习。

所以今天的定位很清楚：出海第一网。网撒出去，才知道这片海有没有鱼、鱼爱吃什么饵。

## 核心知识

### 1. 目标岗位画像：三个方向，优先级排好

市场上和你对口的岗位，名字五花八门，归下来三类：

- **AI Agent 工程师**：JD 核心职责写的是 Agent 编排、工具调用、多 Agent 协作、LangGraph 或同类框架。这是你匹配度最高的方向，23 周的主线项目就是照这个画像长的。
- **AI 应用工程师**：LLM 集成、RAG、对话系统、prompt 工程，覆盖面广，岗位数量最多，简历按「后端工程师 + AI 全栈」的叙事投。
- **大模型应用开发**：偏后端底子加 LLM API 调用，Java 或 Python 团队居多，Day 2 那批工程题就是为这类岗准备的弹药。

优先级按匹配度排：Agent 方向 > AI 应用 > 大模型应用开发。但第一批练手时三类都碰一碰，市场会用约面率告诉你，你的简历在哪类岗位面前最能打。

### 2. JD 关键词匹配自查：两份清单定短板

查漏补缺不能凭感觉，要拿两份清单交叉。

**清单 A，模拟反馈。** 把 Day 5 模拟面试暴露的问题分三类：知识性的（答不上），表达性的（答得出但乱），项目性的（项目讲不深）。知识性的今晚补，直接回 [Day 1](/week23/day1) 和 [Day 2](/week23/day2) 的笔记重背；表达性的别指望闭门练，靠真实面试迭代；项目性的回项目代码里翻，把数据、架构、踩坑三样重新对齐一遍。

**清单 B，JD 关键词。** 收 10 份目标 JD，把技术要求拆成词，和自己的技能对照。判断口径很硬：

- LangGraph、RAG、Agent、Function Calling、向量数据库这些词出现，就是高匹配，你的体系全覆盖，放心投
- 出现你不会的词，数它出现的次数、看它在不在核心职责里。出现三五次还进了职责描述，今晚补；只在任职要求末尾露一面，标记一下就行

23 周体系覆盖了市面上 90% 的常见要求，剩下 10% 按需补：某个垂直领域知识、某家自研框架的名字，临阵补完全来得及。自查表可以直接抄：

| JD 关键词 | 出现次数 | 我会吗 | 对应笔记 | 今晚动作 |
| --- | --- | --- | --- | --- |
| 多 Agent 编排 | 4 | 会 | Day 1 第 18 题 | 无 |
| 某自研工作流引擎 | 3 | 不会 | 无 | 读官方文档 30 分钟，知道定位即可 |

### 3. 渠道策略：每个渠道打法不同

**BOSS 直聘，国内主战场。** 决定性动作是打招呼话术。「你好」「在吗」「还招人吗」这类开场等于把破冰成本甩给对方，HR 一天收几十条，不回。正确姿势是 3 句话一次给全：是谁、最强匹配点、作品链接。模板直接抄：

```text
您好，我是 X 年经验的后端工程师，最近 23 周系统学完 AI Agent 全栈开发。
贵司 JD 里的 LangGraph 编排和 RAG 检索，我都有完整落地项目：主项目是一个
支持工具调用、检查点持久化和流式输出的 Agent 运行时（换成你的一句话版本）。
代码和 161 篇学习教程在这里：github.com/你的ID，方便的话想投个简历。
```

三句是上限，第二句必须贴着这家 JD 改，作品链接必须给。

**内推，成功率最高的渠道。** 去 GitHub、掘金、V2EX、知乎找目标公司的人。你的开源博客就是敲门砖：持续公开输出 23 周这件事本身，就是执行力的证明，比简历上任何一句自评都硬。私信模板：

```text
您好，看到您在 X 公司。我一直在大模型应用方向系统学习并公开输出，
博客已写 161 篇（链接），主项目是 XXX。
最近在看贵司这个岗位：JD 链接。如果方便内推，简历随时发您，打扰了。
```

**猎聘与脉脉，辅助位。** 猎聘上把作品链接填进简历附件和个人主页，完善度权重高；脉脉用来查目标公司的口碑和部门真实状态，面试前刷一遍员工评价，反问环节的问题就有了。

### 4. 作品集：投递前的最后 30 分钟花在这

**GitHub 置顶仓库的 README，一屏讲清。** 面试官在一个 README 上停留不到一分钟，第一屏决定他拉不往下拉。结构照这个来：一句话项目定位、一张架构图、核心技术点列表、快速启动命令、博客链接。架构图没有就现画一张框图（手绘或任意白板工具，十分钟的事），千万别空着。

**博客就是差异化武器。** 面试官点开链接，看到的是 23 周成体系、161 篇从 TypeScript 泛型一路写到 Agent 安全的教程目录，这个画面的冲击力，是「背过几个概念」的候选人给不了的。链接放简历显眼处，技能栏旁边单独一行：「AI Agent 全栈学习博客（161 篇 / 23 周）：URL」。

## 动手任务：今天投出 5 个岗位

拆成 5 步，全程约 3 小时。

**第 1 步：定短板清单（40 分钟）。** 按「清单 A 加清单 B」的办法，产出一张自查表。挑出今晚要补的知识性短板，控制在 3 个以内，多了补不完。

**第 2 步：补短板（60 分钟）。** 回对应笔记重背，或者读官方文档。补完在自查表「今晚动作」一栏画掉，这就是今天的查漏补缺产出。

**第 3 步：磨作品（30 分钟）。** README 按一屏原则过一遍，博客链接确认可访问、无需登录就能看。这个链接今天要出现在每一次打招呼里，它坏了一切白搭。

**第 4 步：选岗位、发话术（40 分钟）。** 从收藏的 JD 里挑 5 个，注意：不要挑最想去的。每个岗位把打招呼话术第二句贴着 JD 改一遍再发，BOSS 直聘发 3 到 4 个，内推私信发 1 到 2 个。

**第 5 步：建表记录（10 分钟）。** 投一个记一行，模板见下一节。今天收工的唯一标准：表里有 5 行。

::: tip 一个提醒
第一批 5 个是练手位，目的是拿真实面试数据：话术有没有人回、八股答得顺不顺、项目讲到第几分钟被打断。练手的数据不理想是常态，这正是它存在的意义。
:::

## 常见踩坑

**坑 1：打招呼三件套全空。** 没有身份、没有匹配点、没有链接，只发「你好在吗」。对方回「你好」之后你还得再说一轮，多数人懒得回。记住 3 句结构，一次给全。

**坑 2：海投 50 个，话术一个模板。** 群发的感觉 HR 一眼能看出来，等于每个都没定制。第一批就 5 个，每个都贴着 JD 改那句最强匹配点，质量换回复率。

**坑 3：简历上找不到作品。** 写了 23 周代码和 161 篇博客，简历上没有链接，相当于考试不带准考证。链接要显眼，别塞进附录角落。

**坑 4：把最想去的公司放在第一批。** 练手期话术最生、状态最冷，最想要的机会应该留给迭代过话术、补过短板的第二批主攻。

**坑 5：用「再准备准备」无限推迟。** 已过的事项：八股 40 题、系统设计、算法、模拟面试。清单都绿了还不投，拖的不是准备，是怕被拒。被拒是漏斗的正常损耗，不是能力判决。

## 自测问题

先自己答，再展开对照。

1. 打招呼话术的 3 句结构是什么？为什么不能只发「你好」？

::: details 参考答案
三句：我是谁（背景加 23 周体系学习）、最强匹配点（贴着这家 JD 改）、作品链接（GitHub 加博客）。只发「你好」是把破冰成本转嫁给对方，HR 一天几十条这类消息，不会回；三句给全，对方看完就能决策要不要简历。
:::

2. JD 里出现一个你不会的技术词，怎么判断要不要今晚补？

::: details 参考答案
看两个维度：出现次数，是否写进核心职责。出现三五次且在职责描述里，今晚补；只在任职要求末尾出现一次，标记了解即可。23 周体系已覆盖 90% 常见要求，剩下的是长尾，按需补，别陷进去。
:::

3. 第一批 5 个岗位为什么不选最想去的？第二批什么时候投？

::: details 参考答案
第一批是练手，目的是拿真实面试数据：回复率、八股熟练度、项目讲述的薄弱点。此时话术最生、状态最冷，好机会应该留给迭代后的主攻。第一批面完 2 到 3 场、复盘写完、话术改完，再投第二批，两批流程并行不冲突。
:::

4. 投递记录表至少要有哪几列？漏斗怎么读？

::: details 参考答案
公司、岗位、渠道、日期、状态、复盘，加一列下一步动作更好。漏斗读法：投得多约面少，问题在简历和话术；约面多一面挂，问题在八股和项目讲述。每周固定时间数一遍，让数据告诉你补哪里。
:::

5. 投出去一周没有回复，说明什么？不说明什么？

::: details 参考答案
说明流程还在走或者岗位已招满，HR 处理周期 3 到 7 天、整体流程 1 到 4 周都正常。不说明你被拒绝，更不说明你不行。已投未复不等于拒绝，状态没变就不需要动作，把注意力放回你能控制的三件事：投递量、话术质量、复盘深度。
:::
