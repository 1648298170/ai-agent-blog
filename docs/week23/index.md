# 第 23 周：面试冲刺

> 所属阶段：全栈整合 + 生产化 + 面试冲刺（第 20–23 周）

## 本周目标

全面进入面试冲刺：刷完 Agent 八股与工程八股题库，完成系统设计模拟、LeetCode 图论与堆专题、完整模拟面试，最终产出面试速查卡并开始投递。

## 本周日程

| 天 | 学习内容 | 动手任务 | 当日产出 |
| --- | --- | --- | --- |
| Day 1 | Agent 八股：ReAct / RAG / MCP / A2A / 评估 / Agent 安全 + 框架横向对比（LangGraph vs OpenAI Agents SDK vs CrewAI vs MS Agent Framework） | 刷 20 道 ReAct 相关题，每道写 3 句话答案 | 八股笔记 v1 |
| Day 2 | 工程八股：死循环/超时/成本/安全 | 刷 20 道工程题，整理“分层防御”话术 | 八股笔记 v2 |
| Day 3 | 系统设计模拟：短链接 / 排行榜 | 45 分钟白板设计一个系统，录音回听 | 设计录音 |
| Day 4 | LeetCode：图 BFS/DFS + 优先队列 | 刷 3 道图题 + 2 道堆题 | 5 道 AC |
| Day 5 | 模拟面试：完整流程 | 45 分钟技术 + 15 分钟项目 + 15 分钟反问 | 模拟反馈 |
| Day 6 | 查漏补缺 + 简历投递 | 根据模拟反馈补短板，投递 5 个目标岗位 | 投递记录 |
| Day 7 | 最终复盘 + 心态调整 | 整理所有笔记，写一份“面试速查卡” | 速查卡 |
