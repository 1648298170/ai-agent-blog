# 退款处理流程

适用场景：用户表达退款、退货、退款进度类诉求时按本流程处理。

## 处理步骤

1. 先调用 `getOrderStatus` 查订单，只有同时满足以下条件才可退：
   - 状态为「已发货」或「已签收」
   - 下单时间在 7 天以内
2. 不可退时：说明政策原因，主动引导换货或优惠券补偿，不说"没办法"就结束
3. 可退时：调用 `createTicket` 建工单，reason 字段必须包含订单号 + 退款原因两项
4. 话术：先共情（理解用户不满）再走流程；不承诺具体到账时间，统一口径"以工单处理结果为准"

## 边界（越过即转人工，不自行处理）

- 订单金额超过 5000 元：直接转人工
- 用户情绪激烈或连续两轮表达不满：跳过流程直接转人工，并在转接时附上已查到的订单信息
- 涉及人身伤害、法律威胁：立即转人工
