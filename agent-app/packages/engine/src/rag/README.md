## 一、RAG 解决什么问题：把"闭卷考试"变成"开卷考试"

LLM 的知识固化在训练参数里，有三个先天缺陷：

1. **有截止日期**——训练之后发生的事一无所知
2. **不知道私有数据**——你公司的制度文档、你的项目代码，它没读过
3. **会编造**——不知道时它会一本正经地瞎说（幻觉）

RAG（Retrieval-Augmented Generation，检索增强生成）的思路：

```
回答问题之前，先去知识库里检索最相关的几段原文，
把原文塞进 prompt，要求模型"只依据资料回答"。
```

模型的**生成能力**（强项）负责组织语言，**记忆**交给外挂的检索系统（可更新、可溯源）——各干各的强项。

## 二、全链路的数学地图

整个 `rag/` 目录对外只有两个动作，每个环节对应一段数学：

```
入库：文档 → ①切块 → ②Embedding(文本→向量) → 存起来
检索：问题 → ②Embedding(问题→向量) → ③余弦相似度 → ④Top-K → 带编号引用
```

| 环节 | 数学算法 | 复杂度 | 代码位置 |
| --- | --- | --- | --- |
| ① 切块 | 定长滑动窗口（步长 = 窗口宽 − 重叠） | O(n) | `chunker.ts` → `hardCut()` |
| ② 文本→向量 | 深度神经网络映射（Transformer + 对比学习） | 模型内部 | `embedder.ts` → `embed()` |
| ③ 相似度 | **余弦相似度** | O(d) 每对 | `store.memory.ts` → `cosineSimilarity()` |
| ④ 找最像 | Top-K 最近邻（本项目暴力扫；工业版 ANN 索引） | O(n·d) | `store.memory.ts` → `search()` |

## 三、Embedding：把"语义"变成"坐标"（②的核心）

**是什么**：一个深度神经网络 `f(文本) → ℝⁿ`，把任意文本压成一个 n 维浮点向量（本项目 GLM `embedding-3` 是 2048 维）。可以理解为：给每段文本在高维空间里安排一个"住址"，**意思越近的文本住得越近**。

**内部两层数学**（发生在模型里，调用方是黑盒，但值得知道）：

1. **Transformer 注意力**：`Attention(Q,K,V) = softmax(QKᵀ/√d)·V`——本质是大量矩阵乘法与点积，让每个词"看"完上下文后更新自己的表示
2. **对比学习（InfoNCE 损失）**——"语义近 = 距离近"的来源：训练时喂海量文本对，正样本对（同一句话的两种说法）在向量空间里**拉近**，负样本对**推远**。训练结束后，"语义相似度"就被固化成了"空间距离"

**为什么这是 RAG 的地基**：它把"判断两段文字是否相关"这个原本需要人读的语义问题，**转化成两个向量算夹角的纯数学问题**——可计算、可索引、毫秒级。

**由此推出一条铁律**（`retrieve.ts` 注释里也强调了）：查询和入库必须用**同一个** embedding 模型。不同模型是不同的坐标空间，跨空间比距离毫无意义——这就是换 embedding 模型必须全库重嵌的原因。

## 四、余弦相似度：只需真正吃透的一个公式（③的核心）

`cosineSimilarity()` 里那一行就是全部数学：

```
                 a · b            n
cos(θ) = ─────────────────  =  Σ aᵢbᵢ / (‖a‖ · ‖b‖)
               ‖a‖·‖b‖          i=1
```

**分子是点积**（对应位置相乘再求和），**分母是两个模长的乘积**（把向量长度归一化掉）。

**手算一个小例子**（2 维便于想象，实际 2048 维同理）：

```
a = [1, 0]      主题：退款
b = [0.8, 0.6]  主题：退货
cos(a,b) = (1×0.8 + 0×0.6) / (1 × √(0.64+0.36)) = 0.8 / 1 = 0.8   ← 挺像

c = [0, 1]      主题：天气
cos(a,c) = (1×0 + 0×1) / 1 = 0                                    ← 无关（垂直）
```

读分：`1` 同一件事；`0.8+` 基本同一主题；`0.5` 相关但细节未必对；`0` 无关；`<0.15` 视为不相关（对应教程里 pgvector "distance > 0.85 拒答"的闸——score = 1 − distance）。

**为什么用余弦、不用更直观的欧氏距离（直线距离）？** 分母把向量**模长**除掉了——模长反映"文本里词有多少"，不代表"主题多强"。一段 500 字详述和一句 20 字问答只要主题相同，方向就该接近；余弦**只比方向、不比长度**，对文本长短天然免疫。（数学补充：向量归一化后二者排序等价，余弦胜在直觉干净。）

**代码里的防御对应数学性质**（对照 `cosineSimilarity()` 注释）：零向量 → 模长 0 → 分母除零 → 返回 0；NaN 坐标会污染点积 → 逐位拦截；溢出产生 NaN → 最终兜底。检索不能被单条脏数据炸掉。

## 五、Top-K 最近邻：从"算相似"到"找最像"（④）

`search()` 做的事：库里每块都算一次余弦 → 降序排序 → 取前 k。

**本项目 = 暴力精确检索**：O(n·d)，n=块数、d=2048。几百块 × 每块几微秒 = 毫秒级，**结果精确、实现透明**——学习阶段就该从暴力开始，先理解"找最像"本身。

**工业版 = ANN 近似最近邻**（教程 week14 pgvector 的主题）：十万块以上暴力扫不动，用索引换精度：

- **HNSW**（分层可导航小世界图）：跳表思想的图版本——建多层"高速公路"，贪心搜索从顶层一路跳到底层，O(log n)，召回 ~99%
- **IVFFlat**：先用 **k-means 聚类**把向量分桶，查询只扫最近的几个桶

算法从"暴力"换成"近似索引"，但 `RagStore.search()` 接口不变——这就是 `types.ts` 留接缝的意义。

## 六、切块的滑动窗口（①）

唯一的字符串算法：窗口宽 `maxLen=500`、步长 `maxLen−overlap=420`，相邻窗口天然共享 80 字。本质是**定长滑动窗口采样**。

**为什么必须有重叠**：切块按长度切，语义不看长度——一句话可能被拦腰切断。重叠让这句话在相邻两块各出现一次，无论从哪个角度问，至少有一块保有完整上下文。详见 `chunker.ts` 头部的三级瀑布图和 S1~S5 攒块推演。

## 八、推荐学习顺序（总计约 3~4 小时）

设计原则：**先静态后动态、先纯函数后有状态、先离线后碰网**——每一步只引入一个新概念，且每一步都有可验证的通关标准，学不会随时停，不会卡在环境问题上。

```text
原理 → 数据形状 → 纯函数 → 有状态 → 带副作用 → 总装 → 实战
```

| 步骤 | 文件 | 学什么 | 通关标准（能做到才往下走） | 时间 |
| --- | --- | --- | --- | --- |
| **0** | 本文（原理篇） | Embedding 是什么、余弦公式、手算例子 | 能回答第七节的 7 个自测问题 | 30min |

### 第 8 步实战命令（最有体感的一步）

在 `agent-app/` 目录下（前置：`.env` 已按 `.env.example` 配好 API Key）：

```powershell
pnpm kb:ingest .\samples\company-faq.md    # 入库：看"切块 N 块"输出 ← 第 2 步的知识
pnpm kb --trace                            # 提问，看 🔎 检索轨迹       ← 第 3/5/7 步串起来
```

trace 里的相似度分数（如 `0.83`）就是第 3 步手算的公式在真实 2048 维上的输出——**理论和现实在这里对上号**，这是整个学习路径的高光时刻。

### 两个随时可回的"加油站"

- **向量概念卡住** → 回本文第三、四节 + 向量最小清单（点积/模长/归一化/余弦/Top-K 五个必会点）
- **某文件读不懂** → 每个文件的头部注释就是该文件的小地图，"为什么"都写在代码旁边

### 为什么是这个顺序（三个原则）

1. **先形状后逻辑**：`types.ts` 是宪法。不知道 `Chunk` 长什么样，后面每个文件的代码都在雾里
2. **每个文件只引入一个新概念**：chunker 引入切块算法（纯函数）、store 引入相似度计算（有状态）、embedder 引入网络调用（副作用）、persistence 引入持久化（I/O）——如果先读 `retrieve.ts`，你会同时面对全部四个概念
3. **离线零件先于在线组装**：步骤 1~4 全程不需要 API Key（selftest 用假模型），步骤 5 起才需要网络

走完这条线，你就具备了改造它的能力——步骤 9 的两个挑战（BM25 版存储、pgvector 版存储）正好对应教程 week14~15，week20 的前端也会直接消费这个模块。
